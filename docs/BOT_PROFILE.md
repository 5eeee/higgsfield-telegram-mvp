## Рекомендации по аватару

- Стиль: dark premium + sci-fi.
- Символ: планета Земля + контур лица + zoom-rings.
- Формат: квадрат 1024x1024.
- Файл логотипа проекта: `assets/earth-zoom-in-logo.svg` (можно экспортировать в PNG для BotFather).

## Что задать в BotFather

- `/setname` -> `Earth Zoom AI`
- `/setdescription` -> используйте "Полное описание" из раздела выше
- `/setabouttext` -> используйте "Короткое описание"
- `/setuserpic` -> загрузите PNG, экспортированный из `assets/earth-zoom-in-logo.svg`
