# QA Test Plan: Earth zoom in Telegram MVP

## 1. Scope

Проверка MVP-бота, который принимает фото лица и генерирует видео через Higgsfield API по фиксированному сценарию `Earth zoom in`.

## 3. UAT сценарий

1. `/start` -> видим приветствие и кнопку.
2. Нажимаем `Создать видео`.
3. Отправляем валидное селфи.
4. Проверяем статус-сообщение.
5. Получаем и воспроизводим видео.
6. Повторяем с невалидным контентом.
7. Повторяем с несколькими пользователями.

Acceptance:
- нет блокирующих дефектов;
- happy path стабилен;
- фиксированный Earth zoom in соблюден.
